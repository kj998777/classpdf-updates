잉크오버 지원

초안 — 게시 전 검토 필요. [ ] 안은 게시 전에 채울 빈칸입니다.

잉크오버(예전 이름 수업 PDF)는 PDF에 필기하고, 외울 곳을 테이프로 가려 복습하고, 문제를 하나씩 크게 띄워 수업하는 앱입니다. 맥과 아이패드에서 씁니다. 기기별로 되는 기능은 기능 차이 표를 보세요.

문의

  • 이메일: [연락처 이메일]
  • 답변: [답변 가능한 요일·시간, 예: 평일 저녁]

문의하실 때 아래를 함께 적어 주시면 빨리 도와드릴 수 있습니다.

  1. 기기(맥/아이패드)와 시스템 버전(예: macOS 15, iPadOS 18)
  2. 앱 버전 — 맥: 메뉴 잉크오버 › 잉크오버 정보 · 아이패드: 설정(톱니바퀴) › 맨 아래 정보
  3. 어떤 순서로 무엇을 했더니 어떻게 되었는지, 가능하면 화면 사진
  4. (맥, 필요할 때만) 앱 기록 파일 ~/Library/Application Support/ClassPDF/main.log — 파일 이름이 들어 있으니, 보내기 전에 열어서 학생 이름 등 보내고 싶지 않은 내용은 지워 주세요.

자주 묻는 질문

필기는 어디에 저장되나요? 원본 PDF가 바뀌나요? 원본 PDF는 바뀌지 않습니다. 필기는 따로 저장됩니다. 맥은 ~/Library/Application Support/ClassPDF/annotations/, 아이패드는 앱 폴더의 숨김 폴더 .classpdf/입니다. 아이패드의 .classpdf 폴더는 지우지 마세요.

PDF를 옮겼더니 필기가 안 보여요. 필기는 PDF가 있던 자리를 기준으로 찾습니다. 원래 자리로 되돌리면 다시 보입니다. 옮기기 전에는 내보내기로 필기를 합친 PDF를 만들어 두거나, 동기화를 켜 두세요(동기화는 파일 내용으로 같은 PDF를 알아봅니다).

맥과 아이패드의 필기를 맞추고 싶어요. 두 기기 모두 설정 › 「동기화 · 필기를 다른 기기와」에서 켜고 같은 클라우드 폴더(예: iCloud Drive)를 고릅니다. 두 기기에 같은 PDF가 있으면 필기가 서로 맞춰집니다. 도구 막대·펜 설정은 맞추지 않습니다.

백업은 어떻게 하나요? - 맥: 설정 › 「자동 정리·백업」 › 필기 백업을 켜면 6시간마다와 앱을 끌 때 구글 드라이브(없으면 iCloud Drive)의 ClassPDF 필기 백업 폴더에 복사합니다. - 아이패드: 보관함에서 백업 폴더를 고르면 수업 PDF 백업 폴더에 PDF·필기·녹음을 복사합니다. 되돌릴 때는 보관함의 ⋯ › 백업에서 되살리기.

맥에서 "확인되지 않은 개발자"라며 열리지 않아요. 앱을 오른쪽 클릭 → 열기 → 열기. 그래도 안 되면 시스템 설정 › 개인정보 보호 및 보안 아래쪽 그래도 열기를 누릅니다.

맥 업데이트는 어떻게 받나요? 앱이 스스로 확인해서 알려 줍니다. 바로 확인하려면 메뉴 잉크오버 › 업데이트 확인…. 나중에를 누르면 다음에 앱을 끌 때 바뀝니다. 필기와 설정은 그대로 남습니다.

무료로 어디까지 쓸 수 있나요? (아이패드) 처음 7일은 모든 기능이 무료예요. 그 뒤에도 필기·테이프로 가리기·스캔본 글자 찾기는 계속 무료이고, 이름표 자동 가리기·테이프 복습·필기 녹음은 맛보기로 조금씩, 수업 모드·문제 찾기는 플랜이 있어야 써요. 공부용·수업용·둘 다 — 한 번 사면 계속 쓰는 구매예요(구독 아님).

다른 아이패드에서 샀거나 앱을 다시 깔았어요. 같은 Apple 계정으로 로그인한 뒤 설정 › 플랜 › 구매 복원을 누르세요. 결제는 다시 되지 않아요.

환불하고 싶어요. App Store 결제는 Apple이 처리해서, 환불도 Apple에서 신청해요: reportaproblem.apple.com

녹음·녹화를 하려는데 소리가 안 들어가요. 마이크 허락이 필요합니다. 맥은 시스템 설정 › 개인정보 보호 및 보안 › 마이크, 아이패드는 설정 › 개인정보 보호 및 보안 › 마이크에서 잉크오버를 켜 주세요.

매쓰플랫·메딕차트 정리 같은 기능이 안 보여요. 학원용 기능이라 새로 설치하면 꺼져 있습니다. 맥의 설정에서 켤 수 있습니다. 아이패드에는 없습니다.

영어로 쓸 수 있나요? 네. 기기 언어가 한국어가 아니면 영어로 나오고, 설정 › 화면 › 언어에서 자동·한국어·English를 고를 수 있어요.

사용 기록이나 자료가 어딘가로 보내지나요? 아니요. 서버가 없고 사용 통계·오류 보고도 모으지 않습니다. 자세한 내용은 개인정보 처리방침을 보세요.
